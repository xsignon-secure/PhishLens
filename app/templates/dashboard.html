DNS provider (one-click fixes)

Connect your DNS provider and fix records with one click: an Apply button appears next to each record in your reports. Token needed: Cloudflare Zone → DNS → Edit; DigitalOcean a read/write API token; deSEC a token from your account page; GoDaddy KEY:SECRET (GoDaddy limits its API to accounts with 10+ domains); Route 53 ACCESS_KEY_ID:SECRET for an IAM user that can change record sets.

Hosted DMARC, SPF & MTA-STS

Point your DNS at PhishLens once, then change policies here instead of editing DNS. Hosted SPF is flattened to IP addresses, so you never hit the 10-lookup limit.
