Is this email really from who it says?

Paste the full headers of a suspicious message. We read the receiving server's SPF, DKIM and DMARC verdict and flag the tricks phishing relies on. Nothing you paste is stored.

Where do I find the headers?

Gmail: open the message, ⋮ menu → Show original → Copy to clipboard.
Outlook (web): open the message, ⋯ → View → View message details.
Outlook (desktop): File → Properties → Internet headers.
Apple Mail: View → Message → All Headers.
